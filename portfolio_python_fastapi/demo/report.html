논리 문서 재구성 부록

유형과 문서 내부 페이지 번호("Page N of M")로, 번호가 없는 URLA는 양식 구조 키(Section 1–9 → 부속서 → Lender Loan Information)로 원래 문서 단위·순서를 추정했습니다. 어느 키도 없는 페이지는 확정할 수 없어 별도 묶음으로 남깁니다.
